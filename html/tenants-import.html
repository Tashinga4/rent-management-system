Excel Format Guide

Your Excel file should have these columns:

  • Name - Tenant full name (required)
  • Email - Email address
  • Phone - Phone number
  • Apartment - Building/Apartment name
  • Rent - Monthly rent amount (required)
  • Move In Date - Format: YYYY-MM-DD
  • Lease End Date
  • Emergency Contact
  • Notes
Auto-Assignment Features
